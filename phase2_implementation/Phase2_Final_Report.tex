\begin{abstract}
Phase 1 planned, with evidence, how every piece of information about a child in the Ghana Socioeconomic Panel Survey would be prepared for a school-dropout early-warning model. This report covers Phase 2: turning that plan into working code and checking it. The plan was built as one scikit-learn \var{Pipeline} around a \var{ColumnTransformer}, with custom preparation steps in \path{src/transformers.py}. It is fitted on the model-building children only (X\_train, 1,307 children from 2009/10) and then applied unchanged to the testing children (X\_test, 1,395 children from 2013/14). The output has exactly the planned size: 33 features become 30, and then 53 numeric columns for XGBoost or 48 for logistic regression, with no missing value left. The three removed features can be rebuilt exactly from the kept ones (0 differences in 3,921 checks), so the structural removals add no extra loss beyond the retained source fields. Eight diagnostic figures inspect the preprocessing steps. Most decisions were carried out as planned; five points changed or were sharpened by what the data showed. A retained fixed CPI adjustment aligns nominal monetary units; other cross-period changes remain descriptive. MI-only feature selection is unstable across folds; a fixed structural/domain rule determines the removals. The hours-missed rule is compared descriptively with median filling; no equivalence claim is made. All four ``was missing'' flags are less frequent later, by different proportions; survey mode alone does not establish the cause. And rank correlation was needed because the ordinary correlation would have missed one repeating pair.
The professor-requested extension evaluates six model families with nested district-grouped tuning and training-only probability calibration. Extra Trees, selected from training validation, achieves average precision 0.134 on the primary later cohort and catches 20 of 76 dropouts with 126 false alarms at 20\% capacity. Explanations and drift diagnostics identify strong geographic dependence and changing missingness patterns. Successful preprocessing execution therefore does not demonstrate reliable temporal prediction.
\end{abstract}

\section{\textbf{Introduction}}
% ===============================================================
\textbf{Aim of this phase.} Phase 1 used the Ghana Socioeconomic Panel Survey \cite{gsps} and decided how to fill gaps, treat extreme values, remove repeating features, encode categories, rescale numbers and split the data with fold-fitted preprocessing \cite{phase1}. Phase 2 has three tasks, which follow the assignment: (1) implement that strategy as fully runnable code with a strict X\_train / X\_test separation; (2) check every assumption with eight diagnostic figures; and (3) record where reality agreed with the plan and where it forced a change.

\textbf{What is in the repository.} \path{src/transformers.py} holds the custom preparation steps; \path{src/pipeline_builder.py} assembles them into the pipeline; \path{phase2_implementation/notebooks/pipeline_execution.ipynb} runs everything from start to finish, saves the eight figures to \path{figures/} at 300 DPI, writes the processed tables to \path{data/processed/} and the decision log to \path{phase2_implementation/decision_log.csv}. The execution verification at the end of this report records the status of the integrated notebook rerun.

\textbf{Scope.} The original eight preprocessing diagnostics are retained. Professor feedback extends the analysis to six model families, training-only tuning and calibration, intervention policies, subgroup performance, retrospective temporal evaluation, and model explanations. Later-wave outcomes are used to report performance, never to fit the frozen model, calibrator, or threshold. Repeated training-CV experiments and earlier descriptive inspection of later outcomes are disclosed: this is not untouched external confirmation.

\textbf{Reading this report.} The opening sections preserve the pipeline, eight visual diagnostics, decision log, and output checks. The model-evaluation section adds the professor-requested evidence and separates exploratory alternatives from the frozen evaluation. The final sections describe limitations and verification; the Appendix explains terminology.

\textbf{One pipeline, two versions.} The pipeline is built with scikit-learn \cite{sklearn}. The same steps produce two versions of the data (Table~\ref{tab:steps}). The \textbf{XGBoost version} \cite{xgboost} keeps numbers in their own units, because a decision tree only compares values; it has 53 columns. The \textbf{logistic regression and PCA version} adds the log on long-tailed features and standardises the 16 numeric/ordinal columns, retains 32 indicator columns on their 0/1 scales, and leaves out one option per label as the reference; it has 48 columns. This follows Phase 1, C1 exactly.

\textbf{How leakage is prevented.} Every step that learns something (averages, middle values, neighbours, cap limits, money ranks, the list of options, the scaler) is inside the pipeline. The pipeline is \emph{fitted} on X\_train only and then only \emph{applied} to X\_test. Inside cross-validation it is fitted again on the building part of each fold. The notebook checks this directly: it saves the fitted pipeline, applies it to X\_test, and confirms that nothing it learned has changed \cite{kaufman2012}. The only step applied outside the pipeline, the inflation adjustment, uses a fixed published number, not the data.

\textbf{The split.} Inputs contain 1,307 training and 1,395 later-period children. Primary temporal evaluation is restricted to the 731 children in 605 new households (76 dropouts), with no shared household or person. Secondary evaluation uses 1,175 new people but allows 370 shared households. Five training folds keep whole districts together. Aggregate later-period covariates and outcomes were already explored, so this is retrospective temporal evaluation, not an untouched external confirmation. These subsets are fixed by IDs, not their outcomes.

\textbf{The inflation factor.} Phase 1 promised to convert 2013/14 money to 2009/10 prices using Ghana's consumer price index. The interview dates in the raw survey files show that the first visit took place from November 2009 to April 2010 and the second, labelled 2013/14, mostly from March to October 2014, with a few households in 2015. Using World Bank annual consumer price inflation for Ghana \cite{wbcpi} (index 2009 = 100: 2010 = 110.7, 2014 = 172.6, 2015 = 202.3), weighted by the number of interviews in each year, the price level was 107.5 at the first visit and 174.0 at the second. Every 2013/14 amount is therefore divided by $174.0/107.5 = 1.62$.

\section{\textbf{Deviations and Rationale}}
% ===============================================================
\subsection{\textbf{Price adjustment and rank interpretation}}
Retain the fixed external CPI conversion (factor 1.62) and learn the rank reference on training rows only. Training-reference ranks bound long-tailed monetary inputs without fitting the later distribution. Previously explored later-period ranks differ from the training median, but that alone cannot identify a causal price or wealth change: composition, measurement and attrition can contribute. No claim is made that inflation explains most of the change or that school policy caused the spending difference. Within-wave test ranking is not used to fit the primary procedure or to choose it from test scores.

The removal list is fixed from feature construction and domain meaning, not from full-training dropout associations. Retain household size and rooms instead of derived crowding; retain parent-alive source fields instead of derived orphan status; retain age and the domain-relevant over-age signal instead of grade. The separate MI-only diagnostic agrees in 1 of 5 folds (Table~\ref{tab:folds}), so it is not represented as a stable selection algorithm. This diagnostic does not change the fixed list. Source identities are checked on all training records, including matching missing values; this is a check of structural removal, not a claim that all preprocessing is lossless.

\subsection{\textbf{Hours missed: an assumption with a sensitivity comparison}}
The retained rule assumes zero missed hours when attendance is recorded; it is not recovery of a known survey answer. It sets 756 blanks to zero and leaves 261 holiday/unknown-attendance cases for the later median fill. The untuned five-fold comparison gives logistic-regression PR-AUC 0.266 for the rule versus 0.275 for median filling, and XGBoost 0.252 versus 0.257. These are descriptive scores with substantial fold variation; no formal equivalence or no-harm conclusion is supported. The sensitivity remains separate; the later source-audited cleaning comparison revisits this assumption under grouped training validation. Temporal test scores must not select it.

\subsection{\textbf{Missing indicators can change meaning across periods}}
Flags are on less often in the later cohort: teacher absent 56.8\% vs 31.8\%, hours attended 21.8\% vs 11.7\%, father's education 7.7\% vs 5.4\%, mother's education 3.8\% vs 1.9\%. Survey mode, coding and cohort composition may all matter; tablet use alone is not established as the cause. Retain the four design/family-context flags as a fixed modelling choice, not because an unadjusted significance test selected them. Compare their behaviour descriptively across periods and retain the uncertainty in transport claims.

\subsection{\textbf{Rank correlation was needed, not the ordinary one}}
The assignment's screening rule is written as $|r|\ge0.85$. To capture monotone curved relationships and reduce sensitivity to extreme values, Phase 1 used the rank (Spearman) correlation $\rho$ with the same threshold. Phase 2 shows why this mattered: for rooms and people per room, $\rho=-0.855$ but the ordinary (Pearson) correlation is only $r=-0.563$, because the relationship is curved (people per room = household size / rooms). With Pearson $r$, this repeating pair would have been missed, and the VIF check also misses it (VIF 1.77). For father alive and lost a parent, both measures give $-0.850$.

\textbf{Final size.} Table~\ref{tab:dims} confirms that the pipeline produces exactly the size planned in Phase 1: 33 features become 30, then 53 columns for XGBoost and 48 for logistic regression, for every child of X\_train and X\_test, with no missing value and no child deleted.

\textbf{Feature count reduced without information loss.} The assignment asks for proof that the reduction from 33 to 30 loses no information. Imputation, capping and ranking still intentionally change information; the full pipeline is not claimed to be invertible.

\textbf{No leakage.} (1) Every learned setting is fitted on X\_train only; the notebook confirms that applying the pipeline to X\_test leaves its fitted settings unchanged. (2) In cross-validation the whole pipeline is re-fitted on the building part of each fold; no district or household is shared between building and checking parts. (3) Later outcomes are not used for fitting or selection. Prior descriptive inspection is disclosed; primary households and people are disjoint.

\section{\textbf{Model Evaluation and Professor-Requested Diagnostics}}
\subsection{\textbf{Training-only model comparison and calibration}}
XGBoost remains the primary benchmark; LightGBM, CatBoost, ElasticNet/L1 logistic regression, Random Forest, and Extra Trees are compared on the same five district-grouped folds. All learned preprocessing, grade-KNN selection and class weights are fitted inside the appropriate training partition. Small, explicitly recorded hyperparameter grids are searched in inner grouped folds. Sigmoid and isotonic calibrators use training out-of-fold predictions with further fit/selection separation; validation and later outcomes do not fit these mappings. Raw and calibrated outputs are both retained because class weighting changes the meaning of uncalibrated probabilities.

The discrimination metric called PR-AUC in earlier sections is specifically scikit-learn average precision (AP), not trapezoidal integration. Recall and precision are reported at the same resource capacity, alongside Brier score, ten-bin equal-width calibration error (ECE), reliability curves, and confusion counts. Five-fold mean AP is distinct from AP of pooled out-of-fold predictions. The training-CV sigmoid mean AP selected Extra Trees (0.303), ahead of Random Forest (0.294) and XGBoost (0.259). This choice was frozen before the reported temporal run. The grids are limited and the training folds have been explored repeatedly; neither exhaustive optimization nor independent confirmation is claimed.

\subsection{\textbf{Frozen retrospective temporal evaluation}}
The primary evaluation contains 731 children from households absent in training, including 76 observed dropouts. The secondary evaluation contains 1,175 children absent as people from training, including 115 dropouts, but may share households. The 1,395-row later table is not wholly independent of training; district overlap also remains. Cohorts are defined by identifiers, not outcomes. Training-only regional prevalence defines high-risk regions (8 and 10); the definition is not updated using later labels.

The frozen policy ranks calibrated risk and selects the top 20\% (146 primary or 235 secondary places), with deterministic hashed-identity tie breaking. Primary results are in Table~\ref{tab:temporal}. All six families lose AP relative to their training CV. CatBoost and Random Forest perform differently in the later cohort, but these results do not authorize replacing the selected Extra Trees model after observing test outcomes.

\subsection{\textbf{Calibration and subgroup allocation}}
Extra Trees primary mean calibrated risk is 12.4\%, versus 10.4\% observed dropout; Brier score is 0.0938 and ECE 0.0197. Secondary mean risk is 12.4\%, versus 9.8\% observed; Brier is 0.0900 and ECE 0.0263. A lower Brier score across periods can reflect lower prevalence, so it cannot alone establish improved calibration. Small high-risk bins have very few observations. Average calibration also hides regional errors and does not establish good ranking.

Regions 8 and 10 together receive 128 of the 146 primary places and contribute 17 true positives and 111 false alarms. Other regions contain 59 dropouts but receive only 18 places, catching three. In region 8, observed dropout falls from 28.0\% in training to 12.8\% (16/125) later, while mean predicted risk is 21.0\%. Region 10 has only 20 later children and one event; its apparently large overprediction is sparse descriptive evidence. Under the same primary policy, both-parent households have 17/48 events caught (35.4\%), compared with 3/20 (15.0\%) in mother-only households. These are descriptive allocation disparities, not causal effects of household type. Counts and sparse-group flags accompany all subgroup results.

\subsection{\textbf{Attrition, ablations, and uncertainty about mechanisms}}
The attrition audit compares baseline covariates and parent co-residence among children with and without an observable subsequent outcome. Unknown outcomes are not relabelled as non-dropout. All predictive results therefore concern observable children; selection into follow-up limits population claims. Inverse-probability-of-follow-up weighting, suggested for consideration by the professor, has not been implemented; it would require a specified follow-up model, overlap checks, weight diagnostics and assumptions about unobserved outcomes.

Training-only ablations remove missingness flags, geography, or the region predictor separately. Effects differ across models; removing all geography reduces mean AP in the compared configurations. This is sensitivity evidence, not proof that flags encode survey artifacts or that geographic predictors generalize. The temporal diagnosis does not justify retrospectively choosing a new ablation from test performance.

\subsection{\textbf{Global and local explanations}}
Held-out XGBoost explanations use native TreeSHAP on the raw log-odds scale. Penalized, class-weighted logistic coefficients are presented as model-score odds ratios, not population causal odds ratios. The final frozen Extra Trees fit is reconstructed from its saved training settings and required to reproduce temporal calibrated predictions (maximum error below $2\times10^{-16}$). Exact TreeSHAP \cite{shap} uses training tree-path counts as its reference. For this classifier, base value plus contributions reconstructs the \emph{uncalibrated positive-class probability}, verified within $4\times10^{-15}$; the contributions do not sum to calibrated risk.

Signed one-hot contributions are summed within their source feature, then absolute values averaged for global ranking. This preserves local additivity but is not a new grouped-feature Shapley game. Region is the largest primary contribution (mean absolute 0.0759), followed by teacher-absence missingness (0.0320) and maternal education (0.0180). One example per TP/FP/FN/TN category in each cohort is selected by the smallest pseudonymous identity hash, avoiding attractive-example selection. SHAP explains model associations; it cannot establish that changing a feature will reduce dropout.

\subsection{\textbf{Source-audited cleaning and exploratory alternatives}}
The original raw/processed tables and temporal results are retained. Separate corrections recognize Wave 1 vacation code 99 in either hours or minutes, mark a conflicting duplicate English-score record unknown, and treat a household asset total as missing when an owned item has unknown/negative value. These corrections preserve row identities, targets, and the target-last schema. Further alternatives use routed subject-teacher absence and relax attendance assumptions. Teacher absence is a proxy, not total lost instruction days; unknown later holiday status is not filled by an inferred holiday. Ambiguous spending blanks and unsupported new plausibility cut-offs are not reinterpreted.

On identical training folds with fixed baseline settings and training-only sigmoid calibration, core corrections change Random Forest mean AP from 0.287 to 0.298 and true positives from 75 to 78 at 260 places. Extra Trees changes from 77 to 79 true positives, while its mean AP falls slightly from 0.286 to 0.285. CatBoost worsens. The routed-attendance Random Forest sensitivity catches 80 events with 180 false alarms, but its score is not directly comparable with the earlier nested-tuned selection. These are mixed, exploratory gains; no improved temporal performance has been established. Definite recording corrections should not be undone to obtain a higher score, and uncertain assumptions should not be adopted solely for a CV gain.

Raw missed-hours missingness changes from 77.8\% in training to 13.5\% in the primary later cohort, and teacher-absence missingness from 56.8\% to 31.7\%. Among observed missed-hours values, medians are 3 and 0 and KS distance is 0.492. These raw diagnostics precede the pipeline's blank-to-zero rule; they are not post-imputation model-input comparisons. Survey routing, composition and behavior can all contribute, so the shift does not identify a single cause of error.

Earlier policy experiments also remain separate. A high-recall training policy catches 185/188 events but flags 1,284/1,307 children. Literacy, funding and routed-teacher enrichment and F1/F2-oriented alternatives expose similar false-alarm trade-offs. They do not establish a deployable policy or supersede the frozen capacity comparison. The demographic age/sex comparator and random allocation provide interpretable resource-matched references.

\section{\textbf{Limitations and Remaining Work}}
The model misses most primary temporal dropouts at the specified 20\% capacity and produces many false alarms. It should not be presented as a validated operational early-warning system. Regional instability, measurement changes, attrition, limited event counts and repeated training-data experimentation limit the conclusions. Repeating the same temporal evaluation verifies reproducibility; it does not create a new independent test.

The completed professor-requested comparisons and explanations are documented. Follow-up weighting has not been implemented. Geography ablations were evaluated internally; a temporal no-geography comparison would require a separately frozen extension and has not been performed. These items are not silently counted as completed. Future feature, geography, calibration or policy changes need a separately specified evaluation and an independent future/external cohort. The evidence supports a reproducible research pipeline, not a deployment-ready classifier.

\section*{\textbf{Appendix: Plain-Language Guide to the Technical Terms}}
The terms below are used in this report; terms already explained in the Phase 1 report keep the same meaning.

{\footnotesize
\noindent\textbf{Pipeline:} A chain of preparation steps followed by a model, run in a fixed order. Fitting it learns every setting from the training data at once.\par\vspace{2pt}
\noindent\textbf{ColumnTransformer:} The part of the pipeline that applies the right preparation to each group of columns side by side (for example, a middle-value fill for lopsided numbers and one-hot encoding for labels).\par\vspace{2pt}
\noindent\textbf{Fit / transform:} \emph{Fit} = learn the settings (e.g.\ a middle value or a cap limit) from data; \emph{transform} = apply the stored settings to any data without learning anything new.\par\vspace{2pt}
\noindent\textbf{X\_train / X\_test:} The children used to build the model (2009/10) and the children kept aside to test it (2013/14).\par\vspace{2pt}
\noindent\textbf{Leakage:} When information from the data used for checking sneaks into building the model, making results look better than they really are.\par\vspace{2pt}
\noindent\textbf{Fold, building part, checking part:} Cross-validation splits X\_train into 5 parts; the model is built on 4 (the building part) and checked on the 5th (the checking part), rotating 5 times.\par\vspace{2pt}
\noindent\textbf{Custom transformer:} A preparation step written for this project (in \path{src/transformers.py}) that follows the same fit / transform rules as the standard scikit-learn steps.\par\vspace{2pt}
\noindent\textbf{KNN (nearest neighbours) filling:} Filling a missing grade from similar training children with numerical differences and category matches treated separately; neighbour count selected within training.\par\vspace{2pt}
\noindent\textbf{Capping:} Pulling an extreme value down to a set limit instead of deleting the child.\par\vspace{2pt}
\noindent\textbf{Rank (0--1):} The position of a value among the training values: 0 = lowest, 0.5 = middle, 1 = highest.\par\vspace{2pt}
\noindent\textbf{Consumer price index, inflation factor:} The official measure of how prices rise; dividing 2013/14 amounts by 1.62 expresses them in 2009/10 prices.\par\vspace{2pt}
\noindent\textbf{One-hot encoding:} Turning a label with several options (e.g.\ 10 regions) into separate yes/no columns.\par\vspace{2pt}
\noindent\textbf{Standardising:} Putting numbers on a common scale with average 0 and spread 1.\par\vspace{2pt}
\noindent\textbf{Correlation ($r$, $\rho$):} How closely two features move together, from $-1$ to $+1$. The ordinary (Pearson) $r$ only sees straight-line relationships; the rank (Spearman) $\rho$ also sees curved ones.\par\vspace{2pt}
\noindent\textbf{VIF:} How much a feature is already explained by all the others together (above 10 = redundant).\par\vspace{2pt}
\noindent\textbf{Mutual information:} How much knowing a feature reduces uncertainty about dropout; it captures any kind of relationship.\par\vspace{2pt}
\noindent\textbf{PCA, component, scree plot:} PCA combines many columns into a few new ones (components) that keep as much of the variation as possible. A scree plot shows how much variation each component keeps, and the cumulative line how much the first $k$ components keep together.\par\vspace{2pt}
\noindent\textbf{Class weighting:} Counting each dropout several times more during training so the model pays enough attention to the rare group.\par\vspace{2pt}
\noindent\textbf{PR-AUC, ROC-AUC:} Scores from 0 to 1 for how well a model puts real dropouts at the top of its risk list. The AP reference is the evaluated cohort prevalence (0.144 in training, 0.104 in the primary later cohort); the ROC-AUC reference is 0.5.\par\vspace{2pt}
\noindent\textbf{Calibration:} Adjusting risk scores toward observed event frequencies using training-only held-out predictions. Calibration can fail under a later distribution shift.\par\vspace{2pt}
\noindent\textbf{Tie-break rule:} The Phase 1 rule used when two repeating features carry similar information: keep the one measured directly and remove the one calculated from others.\par\vspace{2pt}
}
